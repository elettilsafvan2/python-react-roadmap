# Python + React Fullstack Self-Learning Roadmap (42 Days) 🚀

An interactive, modern, fullstack web learning platform built for mastering Python backend and React frontend engineering across 6 structured weeks (42 daily modules) with bilingual (Malayalam & English) guidance.

---

## ✨ Features

- 🗺️ **Comprehensive 42-Day Curriculum**: Divided into 3 strategic phases:
  - **Phase 1 (Days 1–14)**: Python 3 Core, OOP, Data Structures, Algorithms, File Handling, and Backend Fundamentals.
  - **Phase 2 (Days 15–28)**: JavaScript ES6+, DOM, Asynchronous Programming, React (Components, Hooks, State Management), and Tailwind/CSS.
  - **Phase 3 (Days 29–42)**: FastAPI REST APIs, PostgreSQL, Supabase, Authentication, Fullstack Integration, and Capstone Projects.
- 💻 **Dedicated Deep Day Workspace**:
  - Full-page learning mode with sequential navigation (`‹ Prev Day` and `Next Day ›`).
  - Core concepts guide and structured 3-task action checklists.
  - Authentic **VS Code Window** with file tabs (`main.py`, `App.jsx`), line numbers gutter, and breadcrumbs.
  - **In-Terminal Interactive Input**: Direct execution via Pyodide WebAssembly without browser prompt popups.
- 🎯 **Daily Concept Check Quizzes**:
  - 42 bite-sized knowledge quizzes with instantaneous visual feedback and score tracking.
- ✨ **AI Coding Tutor (Google AI Studio / Gemini Integration)**:
  - Slide-over AI assistant drawer powered by `gemini-1.5-flash`.
  - Context-aware code assistance that automatically reads your current active day and editor code.
  - Bilingual support in Malayalam, Manglish, and English with 1-click code copying.
- ☁️ **Supabase Cloud Sync**:
  - Real-time bi-directional progress, quiz scores, subtasks, and personal notes persistence.
- 🌓 **Dynamic Theme System**:
  - Sleek Dark / Light modes with smooth circular mask reveal animations.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla Modern CSS3 (Glassmorphism, custom design system, zero bloated frameworks), Vanilla JavaScript (ES6+)
- **In-Browser Execution**: Pyodide WebAssembly (Python 3.12 runtime directly in browser)
- **Database / Cloud**: Supabase (PostgreSQL REST API)
- **AI Engine**: Google AI Studio Gemini API (`gemini-1.5-flash`)

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve it with any local static server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node (npx)
npx serve .
```

Open `http://localhost:8000` in your browser.

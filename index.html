Developer Quick Reference

Python & Flask Environment

python3 -m venv myenv Create isolated virtual environment
source myenv/bin/activate Activate venv (Mac/Linux)
pip install flask flask-cors flask-sqlalchemy Install backend frameworks & drivers
python3 app.py Run development server (Port 5000)

Vite & React Development

npm create vite@latest frontend -- --template react Scaffold React application
cd frontend && npm install Install dependencies
npm run dev Start hot-reloading dev server
npm run build Generate production bundle
